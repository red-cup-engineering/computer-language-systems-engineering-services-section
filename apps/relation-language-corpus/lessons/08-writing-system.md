# Lesson 08: Writing System

RelConLang is written in Latin today.

```text
mi ga ran do kelu.
ku tu ga kan do kano?
```

The future agency script is only a sketch, but the sketch already teaches what the writing system should make visible.

## Five Visible Parts

```text
top    = charge or dialogue force
left   = agent, source, or provenance role
center = root family
right  = object, kind, or locus role
bottom = aspect or process state
```

## Read A Sentence As A Sign

```text
ta mi ga ran do sava.
```

Ask:

```text
What is the charge? ta = potential
Who acts? mi, marked by ga
What happens? ran = relate
What is related? sava = witness, marked by do
```

The future sign would make those parts visible:

```text
charge:active
role:agent
root:witness
role:object
```

## Technical Sentence

```text
sava pa mi ga ran-en do kelu lo tilo ke vara.
```

Visible parts:

```text
pa = provenance
ga = agent
-en = process
do = object
lo = locus
ke = kind
```

Latin is still the script you use.
The agency-sign sketch is a roadmap for a future script that looks like the grammar it carries.
