# Lesson 09: Making Words

RelConLang words grow from families.

## Root Families

The root `k-l` gives:

```text
kelu = relation
```

Nearby roots give nearby meanings:

```text
koda = obligation
kano = capability
```

Obligation and capability are relation-like.
One binds action; one opens action.

## Templates

The vowels shape the family.

```text
CeCu = carried relation
CoCa = binding force
CaCo = open affordance
CuCu = closure
```

Examples:

```text
kelu = relation
koda = obligation
kano = capability
nulu = refusal
```

## Suffixes

```text
-ai = beginning
-en = ongoing
-um = settled
-o  = released
-e  = quality
```

Practice:

```text
ran-en = relating in process
var-ai = begin transforming
kelu-e = relational
```

Sentence:

```text
rama kelu-e ga mor do sava.
The relation-like agent marks the witness.
```

## Coin Carefully

Roadmap candidates:

```text
mesa = memory
paro = permission
shama = shared attention
```

These are not built words yet.
A new word becomes built only when it enters the manifest, the corpus, the lessons, and the tests.
