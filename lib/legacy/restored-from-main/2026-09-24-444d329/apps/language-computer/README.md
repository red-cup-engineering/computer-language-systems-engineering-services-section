# language-computer

The app form over the `language-*` math layers. The libraries are pure math,
split by layer (`language-algebra`, `-topology`, `-geometry`, `-logic`,
`-analysis`, `-codecs`) and by fiber (`english-language-algebra`, …). This app
binds them into one surface.

```
language-computer read       <text>     full layered reading
language-computer parse      <text>     settled words + dependency arcs
language-computer roles      <text>     semantic role frames
language-computer grammar    <text>     grammaticality verdict
language-computer cohomology <text>     gluing obstruction (H⁰/H¹)
language-computer similar    <a> <b>     ontology similarity
```
