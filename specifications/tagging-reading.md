# Shared tagging reading contract

The language-neutral tag projection preserves communicating's native sentence and word UTF-16 source coordinates. Coordinates that cannot be justified by native articulation remain withheld. It preserves each grammar arc's relation, head/dependent surface text, status and knowledge-family FOUR value unchanged. Status alone is insufficient: both positive-only and negative-only native observations have status decided. These are grammar observations, not evidence for a world claim or permission to act.

The original exact communicating 0.2.1 requirement fixed 0.1.6 incorrectly reading a name property from a knowledge-reading string. The current received supplier is communicating 0.3.1-dev.3: its forest aggregates knowledge-reading strings with Metrologic and reads evidence through SignCell, retaining the same projection semantics. This is a behavior-qualified receiving update, not a claim that the old 0.2.1 API was missing. Owner receiving runs test:source-projection and test:tag-native, comparing the projected arc status/value to the native parser and preserving repeated-token and astral source coordinates.

The public /tag factory and its bundle, tokenize, tagWordPos and tagText operations remain synchronous. Package receiving imports the public self-export and the declared development English /bundle, not a host submodule checkout. Real source spans, FOUR readings and semantic role frames remain required. The current source provider graph is not a frozen install; issuance and native resolver qualification are separate.
